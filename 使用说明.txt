桌宠 · Windows 版
====================

这是从 Mac 版重写的 Windows 版本。目前实现了:
  · 角色贴在桌面右下角,会待机、眨眼、看书、走动等
  · 鼠标可以拖动它;点它一下会说话(连点会有不同反应)
  · 右键角色、或点右下角托盘小图标 → 聊天 / 设置 / 番茄钟 / 陪伴记录 / 退出
  · 能和它聊天(接各种 AI:DeepSeek、智谱、通义、Kimi、
    OpenAI、Anthropic、本地 Ollama 等)
  · **点击、问候、番茄钟等所有台词,都由 AI 按你填的角色设定生成,
    不是写死的。改了人设,台词跟着变,和聊天用同一套设定。**
  · 番茄钟:陪你专注倒计时,到点提醒休息,并说一句符合人设的话
  · 陪伴记录:记录相伴天数、聊天次数,到纪念日会提一句
  · 会看你在用什么软件做出反应(可在设置关闭):
      听歌 → 戴耳机;打字/写代码 → 托腮陪你;看网页/文档 → 看书姿势
      并说一句符合人设的话
  · 电脑快没电时会提醒你充电
  · 天气:自动按你所在城市获取,下雨/下雪/晴天会有不同姿势和台词
  · 心情:会根据时间、天气、你在做什么、互动多少变化,影响它多话还是安静、爱不爱走动
  · 节日:元旦、圣诞等会说句祝福;填了生日到日子会说生日快乐
  · 稀有时刻:偶尔冒一句不期而至的感慨,打破机械感
  · 你离开电脑一阵子,它会自己去睡觉,你回来它就醒;锁屏时睡、解锁时醒
  · 会自然地眨眼,让形象更活
  · 角色设定支持:直接填、导出成文本大段编辑再读回、试一下它会怎么回(不进聊天记录)
  · 场景台词支持:导出编辑、读回;也能在设置里一键按人设重新生成
  · 设置里有「最近的问题」页,能看到哪些功能没取到数据(天气/AI 等),恢复后自动消失
  · 提醒:告诉它"几点提醒我做什么",到点它用符合人设的话喊你
      (这是桌宠自己的提醒,不读取 Windows 系统日历)
  · 角色大小可在 设置→外观 里拖滑块实时调整
  · 没配 AI 时也能用最朴素的内置台词

聊天记录、角色设定、配置都存在:
  C:\Users\你的用户名\AppData\Roaming\DesktopPet\


==========================================
怎么跑起来(两种)
==========================================

【先决条件】电脑上要有 Python。
  没有的话去 https://www.python.org/downloads/ 下载安装,
  安装时**务必勾选 "Add Python to PATH"**。

--- 方式一:直接运行(适合先看效果)---
  双击「运行.bat」
  第一次会自动装界面库(PySide6),等它装完角色就出来了。

--- 方式二:打包成 exe(适合发给别人)---
  双击「打包exe.bat」
  等它跑完,产物在 dist\DesktopPet.exe。
  这个 exe 可以直接双击运行,也能发给没装 Python 的人。


==========================================
怎么让它能聊天
==========================================

1. 右键角色 → 设置 →「对话」标签页
2. 选一个服务商(新手推荐 DeepSeek 或 智谱GLM,后者有免费模型)
3. 去对应后台申请一个 API Key,填进去
4. 点「测试连接」,显示"连接正常"就成了
5. 切到「角色」标签页,把人设填一填(尤其是"说话方式"那栏),保存
6. 右键角色 →「聊天」,开始对话


==========================================
还没做的功能
==========================================

Mac 版里还有天气、日历提醒、看你在用什么软件做出反应、
情绪系统、生活档案等等。这些之后可以在这个骨架上继续加。

==========================================
出问题了
==========================================

· 双击 bat 一闪而过 / 提示找不到 python
    → Python 没装,或安装时没勾 "Add Python to PATH"。重装一次。

· 角色没出现
    → 看看右下角托盘区(时间旁边)有没有小图标,右键它能唤出菜单。
      也可能角色跑到屏幕别的位置了,拖回来即可。

· 打包出的 exe 打不开 / 杀毒报警
    → PyInstaller 打的 exe 偶尔被杀软误报,加个信任即可。
